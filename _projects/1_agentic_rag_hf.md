**Institute**: University Health Network
**Project Status**: Ongoing

## Overview

This project developed and evaluated an agentic Retrieval-Augmented Generation (RAG) system for heart failure management, integrating an LLM-as-a-Judge (LLM-J) to autonomously critique and refine a primary chatbot's outputs.

## Key Features

- **Two-stage feedback loop**: LLM-J evaluates responses on five dimensions—accuracy, safety, robustness, empathy, and clarity
- **Safety-first design**: Multiple safety gates with reliable fallback messaging

## Technologies Used

- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- LLM-as-a-Judge architecture
- Clinical knowledge bases
